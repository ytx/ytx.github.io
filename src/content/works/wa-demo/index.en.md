---
title: wa_demo
summary: A browser that demos multi-user web apps from a script.
---

A dedicated browser for demonstrating and checking multi-user web applications in front of customers. It keeps a separate browser session for each role, such as sales, approver and administrator, so you can switch roles and show the whole flow on one screen.

The flow is written as a scenario in Markdown and stepped through one action at a time on a projector or a shared screen. Narration can be overlaid, and a scenario can run to the end on its own and be recorded as a video. When the target is an Electron desktop app rather than a web app, its windows can be laid out and demonstrated the same way.

The idea is to grow the scenarios with generative AI while the target app is being developed. The scenario format is documented as a manual written for AI to read, and a scenario can be checked before it is run. The source is not public; please get in touch if you are interested.
