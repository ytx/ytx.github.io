---
title: memo3
summary: A notes app where you start writing before naming the file.
---

A desktop notes app that works directly on plain text and Markdown files. I build it for my own use, as a replacement for the Evernote desktop app. Start typing in a new tab and the file is named from its first line, so there is no need to think of a name before you write.

Notes are ordinary `.md` and `.txt` files in a folder. Each folder can be registered as a workspace, and changes made in another editor show up straight away. You can search file names and full text, filter by coloured tags, and keep up to four saved searches as presets; Markdown can be previewed in a separate window and printed.

Edits are saved five seconds after you stop typing, and saving waits while Japanese input is being converted. Key bindings can be Emacs, Vim or VS Code. Installers for macOS (Apple silicon and Intel) and Windows are on the download page. The combination I test is macOS with Emacs key bindings.
