テキストと Markdown のファイルをそのまま扱うデスクトップのメモアプリです。Evernote のデスクトップアプリの代わりとして、自分が使うために作っています。新しいタブで書き始めれば、最初の行からファイル名が自動で付くので、書く前に名前を考える必要がありません。

メモはふつうのフォルダに置かれた `.md` と `.txt` のファイルです。フォルダごとにワークスペースとして登録でき、ほかのエディタで書き換えた内容もすぐに反映されます。ファイル名と本文の全文検索、色付きのタグによる絞り込み、よく使う検索条件を 4 つまで覚えておくプリセットがあり、Markdown は別ウィンドウでプレビューして印刷できます。

編集から 5 秒たつと自動で保存し、日本語の変換中は保存を待ちます。キーバインドは Emacs・Vim・VS Code から選べます。macOS(Apple シリコン・Intel)と Windows 向けのインストーラをダウンロードページで配布しています。動作を確かめているのは macOS と Emacs キーバインドの組み合わせです。
